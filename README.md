# WeatherApp
Steps to run the app.

You need to create a .env.local file where you need to set up the api url and the api key under these variables:
    NEXT_PUBLIC_API_URL=https://api.openweathermap.org/data/2.5/weather
    NEXT_PUBLIC_API_KEY= 

To install packages you might need to run npm i
I used shadcn component library
Then the project should run with the command npm run dev
